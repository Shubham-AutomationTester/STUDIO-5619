# Default dataset inventory

These files describe the default ISSUES_PER_STATUS=25 configuration. Paths are relative to your deployed origin. The 15,000 valid URLs are unchanged when the issue cohort is enlarged. Regenerate the expected oracle with the actual count or download the live `/api/manifest` after changing configuration.

`default-manifest.json` contains every fixture, its behavior and expectation category. `valid-15000-paths.txt` and `additional-292-paths.txt` provide complete newline-delimited inventories. These are expected inputs, not actual crawl or indexing results.
